# Todolist
Application web partagée pour organiser le quotidien et suivre les finances. Construite avec Nuxt, Vue et TypeScript.
## Fonctionnalités
- Agenda et tâches partagés, avec calendrier et rappels visuels.
- Notes, humeur, lieux et moments à conserver.
- Suivi des dépenses, charges récurrentes, épargne et investissements.
- Bilan budgétaire avec indicateurs, conseils et graphiques.
- Présentation du bilan avec export PowerPoint.
- Interface responsive et installable comme PWA.
## Démarrage
```bash
npm install
npm run dev
```
Le serveur de développement Nuxt affiche l’adresse locale dans le terminal. Les fonctions qui utilisent l’API et la base de données nécessitent une configuration serveur adaptée.
## Technologies
Nuxt, Vue, TypeScript, PostgreSQL et Vercel.
